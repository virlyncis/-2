
# Лабораторная работа №2 — Светофор на Arduino (FSM, 2 метода)

Конечный автомат «автомобильный светофор» на Arduino Uno, реализованный двумя способами:
1. **switch-case** — классический FSM (`switch-case.ino`)
2. **table-driven** — таблица `состояние × событие` с указателями на обработчики (`table-driven.ino`)

## Подключение
| Компонент | Пин |
|---|---|
| Red LED | 13 |
| Yellow LED | 12 |
| Green LED | 11 |
| Button (INPUT_PULLUP) | 2 |

## Функциональность
- Цикл: Green (10 с) → Yellow (3 с) → Red (10 с) → Green
- Короткое нажатие кнопки — пешеходный запрос (Red 15 с после Yellow)
- Длинное нажатие (≥ 800 мс) — ночной режим (мигающий жёлтый)
- Serial-команды `EMERGENCY_ON` / `EMERGENCY_OFF` — аварийный режим (мигающий жёлтый)
- Возврат из WARNING — в сохранённое состояние с оставшимся временем
- Неблокирующая логика (`millis()`), debounce 50 мс, логирование в Serial (9600)

## Запуск
1. Открыть нужный `.ino` в Arduino IDE.
2. Плата: Arduino Uno, порт — соответствующий.
3. Загрузить, открыть Serial Monitor (9600).
4. Команды: `EMERGENCY_ON`, `EMERGENCY_OFF`.

## Тесты
1. Базовый цикл без нажатий.
2. Пешеходный запрос во время Green → удлинённый Red.
3. EMERGENCY_ON → WARNING, EMERGENCY_OFF → возврат в цикл.
4. Длинное нажатие → ночной режим, повторное — возврат.
5. Быстрые нажатия → одно событие (debounce).
